# Проверки локальной раскладки

В `files` находятся три синтетических процесса. Корпоративные документы в тестовый пакет не включены.

1. Согласование заявки: три дорожки, возвраты, длинные русские подписи, чтение и обновление одного документа.
2. Четыре применимые ветки и совместный контроль: плотные связи документов. Это отрицательный пример — полный граф непланарен. Сохранение всех связей на одной плоскости несовместимо с нулём пересечений. Проверяется честная диагностика, читаемость основных потоков и отсутствие общих сегментов и наложений текста.
3. Раскрытый подпроцесс: дорожки внутри него, непрерывающий граничный таймер, документы и внешний получатель сообщения.

## Запуск

Для каждого задания из `evals.json` создать отдельный чистый контекст. Передать только выбранную версию навыка, исходный BPMN и prompt. В сравнении использовать снимок прежнего навыка и одинаковый нейтральный renderer. До исправлений сохранять `first-attempt.bpmn` и его настоящий PNG, отдельно сохранять итог, число ручных проходов и временные границы измерения. Недоступные токены указывать как null.

Проверять сохранность семантики, импорт всех уровней, реальные подписи и стрелки независимым аудитом. Обзорные PNG и фрагменты 1:1 открываются для осмотра. Финальное качество и качество первой автоматической попытки оцениваются отдельно. Число сообщений об ошибках аудитора не равно числу уникальных конфликтующих пар.

Локальные unit tests: `python -m unittest discover -s <skill>/tests -v`.
